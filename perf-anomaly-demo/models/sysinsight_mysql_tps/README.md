# MySQL foreground-TPS SHAP model

This directory contains a local TreeSHAP model trained only from measured MySQL
demo windows. It predicts the normal-control TPS retention ratio
`pressure TPS / baseline TPS` from the perf function profile captured during
the pressure phase.

- Training data: `results/mysql_shap_windows/` (three rounds across the six focus
  scenarios; generated by `collect_mysql_shap_windows.py`).
- Target: measured MySQL normal TPCC control TPS retention, not external
  pressure TPS and not a synthetic label.
- Method: `RandomForestRegressor` plus `shap.TreeExplainer` with
  `tree_path_dependent` background counts.
- Validation: grouped by focus scenario so the same scenario never appears in
  both train and held-out folds.

The current training set has only six scenario groups and 18 measured windows.
The model therefore reports actual attributions but is marked
`low_confidence`; it is not used as a tuning decision in the LLM prompt. Retrain
with more measured windows before treating it as advisory evidence.

```bash
python3 perf-anomaly-demo/collect_mysql_shap_windows.py --rounds 3
python3 perf-anomaly-demo/sysinsight_shap.py train-mysql
```
