Redo Log Buffer Working Principle
innodb_log_buffer_size controls the InnoDB redo log buffer size. The default value is 16MB. Increasing this value can reduce disk I/O, especially suitable for large transaction scenarios. When the buffer is full, it triggers the log_buffer_flush_to_disk() function to flush logs to disk.
Log Flush Trigger Conditions
log_buffer_flush_to_disk() is triggered when the log buffer is full, when a transaction commits, or during periodic flushes every second. Frequent calls indicate that insufficient buffer is a typical symptom of performance bottlenecks.

log_buffer_flush_to_disk()
static void log_buffer_flush_to_disk(bool flush) { if (log_sys->buf_free > log_sys->buf_size / 2 || flush) { log_write_up_to(log_sys->lsn, flush); } }
log_write_up_to()
void log_write_up_to(lsn_t lsn, bool flush) { while (log_sys->write_lsn < lsn) { ulint len = log_sys->buf_free - log_sys->buf_next_to_write; if (len > 0) { fil_io(IO_WRITE, log_sys->file, log_sys->write_lsn, (byte*)log_sys->buf + log_sys->buf_next_to_write, len); log_sys->write_lsn += len; log_sys->buf_next_to_write += len; } } if (flush) { fil_flush(log_sys->file); } }
